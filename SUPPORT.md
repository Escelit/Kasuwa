# Support & Community Resources

Thank you for exploring or building with Kasuwa!

---

## Getting Help

### 1. Documentation
Start by reading the project documentation:
- [README.md](./README.md): System overview, architecture, invariants, and threat analysis.
- [docs/protocol.md](./docs/protocol.md): Byte-level wire format and payment request/auth specifications.
- [docs/merchant-risk-policy.md](./docs/merchant-risk-policy.md): Offline risk engine rules and configuration.
- [docs/manual-testing.md](./docs/manual-testing.md): Testing on physical iOS and Android hardware.
- [docs/ops.md](./docs/ops.md): Relayer operations, monitoring metrics, and alert thresholds.

### 2. GitHub Discussions & Questions
If you have questions about architecture, use cases, or local development setup:
- Open a topic in [GitHub Discussions](https://github.com/kasuwa/kasuwa/discussions).
- Search previous discussions before posting to see if your question has been answered.

### 3. Reporting Bugs
If you encounter a reproducible software bug:
- Check existing issues first.
- Open an issue using the bug report template, including your Node, Rust, and OS versions, along with minimal reproduction steps.
- For security vulnerabilities, do **NOT** use public issues; refer to [SECURITY.md](./SECURITY.md).
